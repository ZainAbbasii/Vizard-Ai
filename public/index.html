Questions people ask first.

What kinds of video work best?

Talking-head content: podcasts, interviews, webinars, courses, and recorded calls. Clip quality is lower on chaotic, multi-speaker footage, so plan to review picks.

How are credits counted?

One credit equals one minute of source video you upload, no matter how many clips come out. Trim dead air before uploading to save credits.

Can I connect it to my own tools?

Yes. This project includes a small Node.js API proxy so you can submit a video and fetch clips from your own backend.

Is the demo using real AI?

The sample episode is scripted. Turn on live mode by adding an API key to the server's .env file, and the form will submit real videos.
